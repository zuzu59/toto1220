# z-services

PWA offline pour gérer des services auto-hébergés.

## Stack
- Vite + Vue 3
- Dexie.js
- PWA via `vite-plugin-pwa`

## Lancer
```bash
npm install
npm run dev
```

## Convention de commit
`new|change|fixe|refact|del[:(scope)] description`

Pour le contrôle local : `git config core.hooksPath .githooks`.
